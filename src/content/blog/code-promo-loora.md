2. **Tu n'es pas passé par le lien partenaire.** Ouvre le [lien de l'offre](https://www.loora.com/lp/ai-english-tutor/?via=jeremy) dans un nouvel onglet avant de choisir ta formule.

4. **Navigateur ou bloqueur de publicité.** Teste en navigation privée ou désactive ton bloqueur le temps du paiement.
5. **Compte déjà existant.** Certaines offres ne s'appliquent qu'à un premier abonnement : si tu as déjà un compte, vérifie le total affiché dans ton panier.
6. **Offre modifiée par Loora.** Les conditions peuvent changer. Si rien ne fonctionne, contacte le support de Loora ou dis-le-moi, je mettrai la page à jour.

<h2 id="coupon-reduction-offre">4. Coupon, code de réduction, offre, cashback : quelles différences ?</h2>

Ces termes désignent presque tous la même chose quand on parle de Loora. Voici comment les comprendre :

- **Code promo / coupon / code de réduction / discount code :** une suite de caractères à saisir au paiement. Pour Loora, c'est PARLERMALIN10 (-10 %).
- **Offre / promo :** une remise appliquée automatiquement ou via un lien, comme le forfait annuel (environ 62 % moins cher que le mensuel).
- **Cashback :** une somme reversée après l'achat par un site tiers (iGraal, Poulpeo…). À ma connaissance, Loora n'y est pas référencé : vérifie sur ces sites avant de payer, mais ne renonce pas à une remise immédiate pour une cagnotte incertaine.
- **« -70 % » :** ce chiffre circule sur certains sites de coupons. Il correspond probablement à l'écart entre le mensuel et l'annuel, pas à un code supplémentaire.

Ces remises peuvent changer, notamment lors des périodes de promotions de fin d'année. Je mets cette page à jour quand une offre évolue.
